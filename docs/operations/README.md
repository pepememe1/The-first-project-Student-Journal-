# Эксплуатация GradeBookAI

Регламенты для того, кто сопровождает сервер и выпускает обновления. В отличие от
`docs/plans/` (что собираемся сделать) и `docs/security/` (как устроена защита), здесь —
что делать руками и в каком порядке.

| документ | когда открывать |
|---|---|
| [SUPPORT-HANDOVER.md](SUPPORT-HANDOVER.md) | принимаете сервер; ежедневные проверки; частые ситуации; выпуск обновлений |
| [DISASTER-RECOVERY.md](DISASTER-RECOVERY.md) | авария, восстановление из копии, переезд на новую машину |
| [KEY-ROTATION.md](KEY-ROTATION.md) | смена любого ключа: плановая или после утечки |
| [ACCESSIBILITY.md](ACCESSIBILITY.md) | вопрос о доступности для людей с ограничениями; что проверять в новых экранах |

Рядом: модель ПДн — [../security/PDN-MODEL.md](../security/PDN-MODEL.md), реагирование на
инциденты — [../security/INCIDENT-RESPONSE.md](../security/INCIDENT-RESPONSE.md), сроки
хранения — [../security/DATA-RETENTION.md](../security/DATA-RETENTION.md).
