# Доступность интерфейса (a11y): что есть и чего нет

> Замер по коду `web/src` 27.09.2026 (Release 4.1), дополнен 30.09.2026. Интерфейс один на сайт, программу и
> телефон, поэтому всё ниже относится ко всем трём. Ориентир — WCAG 2.1 уровня AA
> (в России — ГОСТ Р 52872-2019, тот же набор требований).
>
> ⚠️ **Заявления о соответствии нет и делать его нельзя.** Проверки программой чтения с
> экрана (NVDA, TalkBack) не было, контраст по всему интерфейсу не измерялся. Документ —
> честная карта, а не сертификат: покупателю стоит показывать его как есть.

## 1. Что сделано

| требование | как | где |
|---|---|---|
| язык страницы | `<html lang>` меняется вместе с языком интерфейса (ru/en/zh) | `web/src/stores/locale.js` |
| крупный шрифт | три ступени (×1, ×1.15, ×1.3), растёт весь интерфейс через `rem` | «версия для слабовидящих», `web/src/stores/a11y.js` |
| высокий контраст | вторичный текст становится полным, границы жёстче | там же, класс `gb-contrast` |
| меньше движения | `prefers-reduced-motion` гасит анимации | 21 файл, в том числе появление сообщений и маскот |
| подписи у кнопок-значков | `aria-label` у КАЖДОЙ кнопки без текста (30.09.2026: подписаны последние 24 — крестики окон, корзины, «назад») | сторож `web/tests/dialogA11y.test.mjs` по всему `web/src` |
| видимый фокус | `focus-visible` | 8 файлов, включая кнопки удаления в модерации (они же видны на тач-экране) |
| закрытие окон с клавиатуры | Esc | 8 компонентов |
| ошибки | `role="alert"` | только модерация и файлы курсов; форма входа — нет |
| текстовая альтернатива картинок | `alt` | 24 из 27 мест с `<img>` |
| вибрация | только там, где палец действует вслепую; настройка видна лишь на тач-устройствах | `web/src/utils/device.js` |
| окна — диалоги (30.09.2026) | `role="dialog"`, `aria-modal`, подпись по заголовку, Tab по кругу внутри окна, возврат фокуса на кнопку-источник | директива `v-dialog` (`web/src/directives/dialog.js`) на всех 21 окне; сторож `web/tests/dialogA11y.test.mjs` |
| живая область уведомлений (30.09.2026) | контейнер тостов `aria-live="polite"` существует заранее; ошибки — `role="alert"`; у крестика подпись | `web/src/components/ui/ToastHost.vue` |
| «к содержимому» (30.09.2026) | первая остановка Tab, видна только в фокусе, переводит фокус на `<main>` | `web/src/layouts/AppShell.vue` |

## 2. Чего нет (по важности)

| пробел | чем грозит | что сделать |
|---|---|---|
| контраст измерялся только у палитры графиков | вторичный серый текст может не дотягивать до 4.5:1 | замер токенов `--gb-*` в обеих темах |
| таблицы журнала — сетка без заголовков строк для чтения с экрана | чтение оценок по клеткам без привязки к студенту | `scope` у заголовков, подпись таблицы |
| проверка программой чтения с экрана | — | прогон основных сценариев в NVDA и TalkBack |

## 3. Как проверять изменения

- Новая кнопка без текста — с `aria-label`, переведённым в трёх локалях.
- Новая анимация — под `prefers-reduced-motion`.
- Новое окно — закрывается Esc и стоит под `v-dialog` (роль, фокус; держит сторож).
- Сторожа, которые уже держат часть правил: `web/tests/haptics.test.mjs` (вибрация),
  `web/tests/i18n.test.mjs` (подписи в трёх локалях), `web/tests/adminMessengerStates.test.mjs`
  (кнопки удаления видны с клавиатуры и на тач-экране).
