# Начальные SLO GradeBookAI

Это цели для staging-нагрузочного теста, а не утверждение о текущем боевом результате.
Ни одна цель не считается достигнутой до прогона через полный путь Caddy/TLS → Uvicorn →
SQLite/SQLCipher с синтетическими данными.

## Цели первого baseline

| Сценарий | Цель p95 | Цель ошибок |
|---|---:|---:|
| `/health` | ≤ 250 мс | < 0,1 % |
| чтение списка чатов | ≤ 750 мс | < 1 % |
| открытие страницы журнала | ≤ 1000 мс | < 1 % |
| запись оценки | ≤ 1500 мс | < 1 % |
| WebSocket reconnect | ≤ 3000 мс до восстановления | без потерянных подтверждённых сообщений |

Порог p99 и предельное число одновременных соединений не фиксируем до измерения: их
значения зависят от размера базы, шифрования, одного writer и выбранного сценария.

## Что измерять вместе с SLO

- p50/p95/p99 и HTTP-ошибки;
- CPU, RSS и число активных запросов;
- время ожидания SQLite writer;
- размер ответа и число строк, обработанных поиском;
- число WebSocket-соединений, reconnect и потерянных/дублированных событий;
- лаг очереди и время публикации;
- поведение при рестарте и временной недоступности realtime-транспорта.

## Ограничения данных

В нагрузочные журналы не попадают ФИО, email, тело сообщения, JWT, IP и полный URL с
параметрами. Используются синтетические пользователи и сообщения.
