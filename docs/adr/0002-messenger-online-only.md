# ADR-0002: Мессенджер только онлайн

## Status

Accepted

## Date

2026-09-12

## Контекст

Мессенджер содержит личные сообщения, права участников, модерацию, реакции и
уведомления. Копирование этих сущностей в локальный синк потребовало бы повторить
контроль доступа во множестве выборок и оставило бы тела переписки на общем компьютере.

## Решение

Мессенджер хранится и читается на сервере. Клиент использует HTTP/WebSocket, а при
временном разрыве показывает состояние связи и повторяет безопасные операции по уже
существующему контракту.

## Альтернативы

- Полный локальный кэш переписки: риск ПДн и второй набор правил видимости.
- Redis как хранилище сообщений: нет требуемой SQL-истории, аудита и семантики удаления.

## Последствия

Офлайн-журнал и онлайн-коммуникация остаются разными подсистемами. Для масштабирования
realtime сначала потребуется durable event-контур; простой Pub/Sub не становится
источником истины.

## Rollback

Откат транспортной оптимизации возвращает HTTP polling/WebSocket к прежнему Python-пути,
не меняя таблицы сообщений и их права.
