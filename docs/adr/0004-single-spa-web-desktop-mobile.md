# ADR-0004: Одна SPA для веба, десктопа и Android

## Status

Accepted

## Date

2026-09-12

## Контекст

Десктоп открывает ту же Vue SPA через локальный сервер, Android использует Capacitor,
а сайт получает её с HTTPS-сервера. Три отдельные реализации UI разошлись бы в поведении
доступности, Вектора и мессенджера.

## Решение

Пользовательский интерфейс и клиентские контракты живут в `web/`. Различия платформ
выражаются узкими capability-gate и оболочкой, а не копированием страниц.

## Альтернативы

- Нативные экраны для каждой платформы: больше контроля над устройством, но три места
  для каждой правки и высокий риск расхождения.
- Общий серверный HTML: теряется офлайн-оболочка и текущая модель OTA.

## Последствия

Правка веба требует веб-тестов, production-сборки и проверки мобильного viewport. Смена
нативной Android-части дополнительно требует APK-проверки; обычная UI-правка едет OTA.

## Rollback

Откатить веб-артефакт на предыдущую сборку и не менять нативный APK, если нативный код
не менялся.
