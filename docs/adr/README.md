# Architecture Decision Records

Здесь фиксируются решения, которые влияют на границы системы и стоят дорого при
пересмотре. Запись объясняет контекст и компромисс; код и тесты остаются источником
фактического поведения.

## Правила

- Номер не переиспользуется.
- Решение, которое изменилось, не переписывается: создаётся новая запись со ссылкой на
  прежнюю.
- `Accepted` означает действующее решение, `Proposed` — проверяемую гипотезу, которая
  ещё не включена в продукт.
- Измерения помечаются как измеренные только при наличии команды, окружения и результата.
