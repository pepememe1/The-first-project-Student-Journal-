# MESSENGER-ADDON-PLAN-GPT

> Дополнение к существующим планам мессенджера GradeBookAI. Основано на
> анализе лучших функций Telegram, Discord, Slack, Microsoft Teams и
> WhatsApp.

# Приоритет 1

## 1. Закрепленные чаты и папки

-   Закрепление важных чатов.
-   Автоматические папки: Все, Личные, Преподаватели, Студенты, Группы,
    Каналы, Избранное, Архив.

## 2. Архив чатов

-   Возможность архивировать завершённые чаты без удаления.

## 3. Избранное (Saved Messages)

-   Личный чат пользователя для хранения заметок, файлов, ссылок и кода.

## 4. Черновики

-   Автоматическое сохранение неотправленного текста.

## 5. История редактирования

-   Отдельная таблица истории изменений сообщений для модерации.

## 6. Кто прочитал сообщение

-   Просмотр списка пользователей, прочитавших сообщение.

# Приоритет 2

## 7. Голосовые сообщения

-   Запись удержанием кнопки.
-   Прослушивание прямо в чате.

## 8. Голосовые комнаты

-   Постоянные голосовые комнаты для групп.

## 9. Треды (Threads)

-   Ветки обсуждений для отдельных сообщений.

## 10. Календарь событий

-   События внутри групп с напоминаниями.

# Приоритет 3

## 11. Умные уведомления

-   Напоминания о начале занятий и важных событиях.

## 12. Системные каналы

-   Автоматические каналы: Расписание, Замены, Объявления, Практика.

## 13. Быстрые ответы

-   Кнопки «Спасибо», «Хорошо», «Принято» и т.д.

## 14. Шаблоны сообщений преподавателя

-   Часто используемые ответы одним кликом.

## 15. Отложенная отправка

-   Отправка сообщений по расписанию.

## 16. Напоминания о сообщениях

-   Создание напоминаний на основе сообщений.

# Приоритет 4 (AI)

## 17. AI-поиск

-   Поиск по смыслу, а не только по ключевым словам.

## 18. AI-сводка переписки

-   Автоматическое краткое резюме длинных обсуждений.

## 19. AI-напоминания

-   Предложение создать напоминание из текста сообщения.

## 20. Поиск по вложениям

-   Фильтрация PDF, DOCX, изображений, видео и других файлов.

# Уникальные функции GradeBookAI

## Контекстные чаты уроков

Каждый урок автоматически получает собственный чат.

## Чаты домашних заданий

Каждое домашнее задание имеет отдельное обсуждение.

## Обсуждение оценки

Приватный диалог преподавателя и студента по конкретной оценке.

## AI-помощник

Команды вида `@AI объясни тему`, `@AI сделай краткий конспект`.

## AI-карточки

Создание карточек для повторения и мини-тестов по загруженным
материалам.
