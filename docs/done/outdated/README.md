# Устаревшие снимки

Сюда переезжает документ, который **перестал описывать продукт**, но ценен как история
решений. Это НЕ «сделано»: у верхнего уровня `docs/done/` у каждого плана названо
доказательство в продукте, а у этих документов доказывать нечего — часть их утверждений
просто перестала быть правдой.

⚠️ **Зачем отдельная папка, а не общая куча в `docs/done/`.** `docs/done/` заведён, чтобы
на вопрос «это уже реализовано или ещё нет» отвечал состав папки. Положи туда же
документы, где половина пунктов не сделана, а другая половина описывает удалённую
архитектуру, — и папка «сделано» начнёт врать, против чего её и заводили.

⚠️ **Читать как историю, а не как инструкцию.** Здесь уверенно написано про PostgreSQL на
бою, пакет `vector/`, обезличивание ФИО перед LLM, Google Translate и `.exe` 3.7.3.
Ничего из этого в продукте нет. Правда о текущем состоянии — в коде, `CHANGELOG.md`,
`README.md` и живых планах в `docs/`.

⚠️ **Открытые пункты отсюда не потеряны.** Перед переносом (16.09.2026) каждый документ
сверен с живыми планами; то, что нигде больше не было записано, перенесено в
`docs/QUEUE.md`, раздел «Перенесено из устаревших планов».

Ссылки на прежние пути держит `server/tests/test_done_docs.py`: файл лежит здесь — значит,
ни одной ссылки на его старое место остаться не должно, и каждый файл обязан быть назван
