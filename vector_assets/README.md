# vector_assets — арт маскота «Вектор»

Сейчас здесь лежат ВРЕМЕННЫЕ заглушки (нарисованы кодом).
Арина, когда будет настоящий арт — просто замени файлы с теми же именами,
программа подхватит их сама, ничего в коде менять не нужно.

## Четыре состояния (4 файла)

| Файл            | Состояние   | Когда показывается                                        |
|-----------------|-------------|-----------------------------------------------------------|
| 1_idle.png      | Статика     | Курсор над чатом, Вектор «слушает» и ждёт вопрос           |
| 2_thinking.png  | Обдумывание | Вопрос отправлен; и ещё 1 секунду после прихода ответа     |
| 3_speaking.png  | Говорит     | Открыт рот; висит 5–7 секунд в зависимости от длины ответа |
| 4_away.png      | Ожидание    | Курсор НЕ над чатом (пользователь работает с журналом)     |

## Технические требования

- Формат: PNG с ПРОЗРАЧНЫМ фоном (альфа-канал обязателен).
- Размер холста: 1024×1024 px (рисуй крупно — программа сама ужмёт до 140 px).
- Персонаж по центру, без полей впритык к краям (оставь ~5% отступа).
- Все 4 кадра — ОДИН ракурс и одна поза корпуса, меняются только морда/глаза/рот.
  Тогда смена состояний выглядит как живая мимика, а не телепортация.
- Персонаж смотрит ВЛЕВО-вперёд или прямо: когда панель переносят вправо,
  программа зеркалит картинку автоматически.

## Хочется настоящую анимацию?

Вместо одиночного файла можно положить ПАПКУ с кадрами — программа будет
листать их по кругу (~6 кадров/сек):

    vector_assets/idle/01.png, 02.png, ...
    vector_assets/thinking/01.png, ...
    vector_assets/speaking/01.png, 02.png   ← например, рот открыт/закрыт
    vector_assets/away/01.png, ...

Кадры берутся по алфавиту. Папка имеет приоритет над одиночным файлом.
Для «речи» достаточно 2 кадров (рот открыт / прикрыт) — уже будет казаться,
что Вектор разговаривает.
