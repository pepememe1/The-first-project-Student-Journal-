# GradeBookAI — закрытый электронный журнал с ПДн студентов, а не публичный сайт.
# За входом индексировать нечего: всё отдаётся только по роли и токену.
# Это ПРОСЬБА к добросовестным краулерам (Google/Yandex её чтут). Недобросовестных
# ботов и сканеры отсекает fail2ban по журналу Caddy (фильтр caddy-scanner), а не
# этот файл — robots.txt защитой не является, только гигиеной.
#
# ⚠️ ЕДИНСТВЕННОЕ ИСКЛЮЧЕНИЕ — /offer.html (решение Ярослава, 24.08.2026).
# Это одностраничник для приёмной комиссии, он и написан, чтобы его читали снаружи;
# при полном запрете его нельзя было найти поиском вовсе, а вся разметка schema.org
# на нём была бы мёртвым грузом. Открыт РОВНО он и ресурсы, без которых Google не
# отрисует страницу и не заберёт логотип из JSON-LD (icons/, fonts/, favicon).
# Правило длиннее Disallow, поэтому у Google и Яндекса оно и побеждает — приоритет
# по длине пути, а не по порядку строк.
#
# ⚠️ ВТОРОЕ ИСКЛЮЧЕНИЕ — /privacy.html и /terms.html (29.08.2026), и оно НЕ по нашему
# усмотрению. Пункт 1 части 2 статьи 18.1 152-ФЗ обязывает оператора опубликовать
# документ, определяющий политику обработки персональных данных, и обеспечить к нему
# НЕОГРАНИЧЕННЫЙ доступ. Политика, открывающаяся только после входа в кабинет, этому
# требованию не соответствует. Пользовательское соглашение открыто по той же причине:
# это оферта, акцептуемая до создания учётной записи, — прочитать её надо ДО входа.
#
# ⚠️ ЧЕГО ЗДЕСЬ БЫТЬ НЕ ДОЛЖНО: ни одного Allow на /web/, /api, /login, /downloads
# и вообще на что-либо за входом. Одна такая строка открывает краулеру кабинет с
# ПДн студентов. Держит web/tests/offerMeta.test.mjs.
# ⚠️ ТРЕТЬЕ ИСКЛЮЧЕНИЕ — сама главная «/» (страница входа), РОВНО она (`$` — конец
# адреса), 01.10.2026. При полном запрете Google показывал адрес сайта без описания
# («информация недоступна») и то выкидывал его из выдачи, то возвращал, а Яндекс не
# показывал вовсе. На странице входа нет ничего, кроме формы и описания журнала.
User-agent: *
Disallow: /
Allow: /$
Allow: /offer.html
Allow: /privacy.html
Allow: /terms.html
Allow: /icons/
Allow: /fonts/
Allow: /favicon.svg
Allow: /sitemap.xml
