# 📚 GradeBookAI — Электронный журнал ВСГУТУ
**Релиз 1.0** · Python · PySide6 · SQLite · OpenRouter AI

> Электронный журнал оценок и посещаемости для учебных заведений с встроенным ИИ-ассистентом.
> Разработан студентами ВСГУТУ по специальности «Информационные системы и программирование».

---

## ✨ Возможности

### 👨‍🏫 Для преподавателя
- Ведение журнала посещаемости и оценок по группам и предметам
- Поддержка типов занятий: **Лекция** (1-й и 2-й час), **Практика**, **Экзамен**
- Автоматическое определение даты пересдачи при неудовлетворительных оценках
- Добавление, удаление и редактирование студентов прямо в таблице
- Импорт студентов из Excel-журналов колледжа (формат ВСГУТУ) и стандартных таблиц
- Импорт данных из внешней базы SQLite
- Экспорт журнала в Excel с форматированием
- ИИ-ассистент для анализа успеваемости группы

## 🤖 ИИ-ассистент

Программа интегрирована с **OpenRouter** и использует модель `stepfun/step-3.5-flash`.
ИИ работает в трёх режимах:

| Режим | Что умеет |
|---|---|
| **Студент** | Рассказывает об оценках, посещаемости и среднем балле конкретного студента |
| **Преподаватель** | Анализирует успеваемость группы, отвечает на вопросы по ведению журнала |
| **Администратор** | Предоставляет сводную динамику по системе |

## 🔒 Безопасность

- Все данные (преподаватели, студенты, группы, API-ключ) хранятся в зашифрованном файле `secure_data.enc`
- Шифрование построено на пароле администратора — открыть файл вручную невозможно
- Пароли преподавателей хранятся в зашифрованном хранилище
- API-ключ OpenRouter никогда не отображается в открытом виде

## 🚀 Установка и запуск
<img width="497" height="384" alt="image" src="https://github.com/user-attachments/assets/a31b606d-5375-47c7-b7e5-12ae0ba57473" />

**Требования:**
- Python 3.10+
- Windows 10/11

**Установка зависимостей:**
```bash
pip install PySide6 openpyxl requests cryptography
```

**Запуск:**
```bash
python main.py
```

**Сборка EXE:**
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=icon.ico main.py
```
Готовый `.exe` появится в папке `dist/`. Файлы данных (`secure_data.enc`, `vsgutu_grades.db`) создаются рядом с исполняемым файлом.

---

## 📖 Первый запуск

1. Запустите программу
2. Войдите в панель администратора: **5 кликов по логотипу**
3. Логин: `admin_vsgutu`, пароль задаётся при первом запуске
4. Создайте группы и назначьте им предметы
5. Добавьте преподавателей и назначьте им предметы и группы
6. Студентов добавьте вручную или импортируйте из Excel
7. *(Опционально)* Укажите API-ключ OpenRouter для работы ИИ
