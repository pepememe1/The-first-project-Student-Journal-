# Тест с другом за 15 минут (гайд для чайника, бесплатно)

Цель: ты на своём ПК, друг — в другом городе/интернете, и он видит данные,
которые ты завёл. Без денег.

---

## Сначала — как это вообще устроено (простыми словами)

- **Сервер** — это «общая папка с данными» в интернете. Там лежат студенты,
  оценки и т.д. Сервер мы запустим у тебя на компе.
- **Программа** (у тебя и у друга) — пустая коробка. Сама по себе данных не
  хранит надолго. Она **скачивает** данные с сервера и **отправляет** туда свои.
  Как почта/Telegram: приложение пустое, пока не войдёшь и оно не скачает.
- **Публичный адрес** — это интернет-ссылка на твой сервер, которую видно из
  любой точки (например `https://abc-xyz.trycloudflare.com`). Домашний адрес
  `192.168.x.x` виден только в твоей квартире — другу он бесполезен. Поэтому
  делаем публичный.
- **Почему у друга «пустая прога» наполнится:** он вводит логин/пароль → прога
  идёт по публичному адресу на ТВОЙ сервер → скачивает оттуда данные. Данные
  приходят не из его компа, а с сервера.

Картинка:
```
Ты (админ) → заводишь данные → они улетают на СЕРВЕР (твой ПК + публичный адрес)
Друг → запускает прогу → логинится → СКАЧИВАЕТ данные с того же сервера
```

---

## Что понадобится (всё бесплатно)
1. Питон с зависимостями (уже есть у тебя).
2. `cloudflared` — бесплатная программка, делает публичный адрес. Один файл .exe,
   качается с сайта Cloudflare (поиск: «cloudflared windows download»).
3. Собранная программа GradeBookAI (.exe) — чтобы отдать другу.

---

## Шаг 1. Запусти сервер (у себя)
```
cd server
python run.py
```
Проверь в браузере: http://localhost:8000/health → должно быть `{"status":"ok"}`.
Окно не закрывай — сервер должен работать всё время теста.

## Шаг 2. Сделай адрес публичным (бесплатно)
В ДРУГОМ окне терминала запусти cloudflared:
```
cloudflared tunnel --url http://localhost:8000
```
Он напишет строку вида:
```
https://abc-xyz-123.trycloudflare.com
```
**Это и есть публичный адрес твоего сервера.** Скопируй его. Это окно тоже не
закрывай. (Адрес временный — при перезапуске cloudflared он меняется.)

Проверь: открой `https://abc-xyz-123.trycloudflare.com/health` в браузере с
телефона (выключи Wi-Fi, через мобильный интернет) → если `{"status":"ok"}`,
значит сервер виден из любого интернета. 🎉

## Шаг 3. Стань админом и заведи данные
В своей проге рядом с ней создай текстовый файл `api_config.json` (в Блокноте):
```json
{ "api_url": "https://abc-xyz-123.trycloudflare.com" }
```
Запусти прогу → войди логином `admin` → задай пароль (первый запуск). Заведи
пару студентов и **учётку для друга**: преподаватель или студент с логином и
паролем (например логин `drug`, пароль `drug12345`). Данные сами уйдут на сервер.

## Шаг 4. Собери прогу для друга и положи рядом адрес
У тебя уже был собранный .exe (в `D:\GradeBookAI`) — собери НОВУЮ версию тем же
способом (PyInstaller), потому что старая сборка без синхронизации.

Два варианта отдать другу адрес сервера:
- **Проще:** рядом с .exe положи файл `api_config.json` с тем же содержимым, что
  в шаге 3 (тот же публичный адрес). Друг его НЕ создаёт — ты даёшь готовый.
- **Совсем без файла:** перед сборкой впиши адрес в `app_settings.py`:
  `DEFAULT_API_URL = "https://abc-xyz-123.trycloudflare.com"` — тогда адрес
  «зашит» в .exe и отдельный файл не нужен.

Заархивируй папку с .exe (и `api_config.json`, если выбрал первый вариант) в zip.

## Шаг 5. Друг запускает
Отправь другу zip (любым способом: облако, мессенджер). Друг:
1. Распаковывает, запускает `GradeBookAI.exe`.
2. Вводит логин `drug` и пароль `drug12345` (которые ты завёл в шаге 3).
3. Прога идёт на твой сервер по публичному адресу и **скачивает данные** —
   друг видит студентов/группы, которые ты завёл.

Если друг видит данные — связка работает из любого интернета. ✅

---

## Частые затыки
- **У друга пусто / «не входит».** Проверь, что оба окна (сервер и cloudflared)
  у тебя ОТКРЫТЫ, и что в `api_config.json` друга стоит АКТУАЛЬНЫЙ публичный
  адрес (он меняется при перезапуске cloudflared).
- **«Где друг возьмёт api_config.json?»** Его создаёшь ТЫ (Блокнотом) и кладёшь в
  zip рядом с .exe. Либо зашиваешь адрес в сборку (шаг 4, вариант 2).
- **«Откуда прога знает адрес API?»** Из `api_config.json` рядом с .exe, или из
  зашитого `DEFAULT_API_URL`. Больше неоткуда — ты задаёшь это сам.
- **Адрес постоянно меняется.** На бесплатном быстром туннеле — да. Для
  постоянного адреса нужен бесплатный аккаунт Cloudflare + свой домен, или
  боевой сервер (см. DEPLOY.md). Для теста просто обновляй адрес в `api_config`.
