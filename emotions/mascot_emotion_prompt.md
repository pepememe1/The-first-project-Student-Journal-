# Промпт для Claude Code: система эмоций и поз маскота-кота в GradeBookAI

## Контекст

В GradeBookAI у ученика в чате с ИИ-помощником сейчас работает анимация
состояния чата (4 кадра в `assets/речь/`: `говорит.png`, `думает.png`,
`ждет.png`, `молчит.png`) — она показывает, печатает ли ИИ ответ прямо
сейчас, и не зависит от успеваемости.

Нужно добавить **второй, независимый слой** — эмоции маскота-кота,
который будет:
1. Показываться в советах от маскота (диалоговое облачко на дашборде
   ученика — фича `loadTip()` / умный совет, которая сейчас выводит
   только текст без картинки).
2. Меняться в зависимости от успеваемости ученика и разовых событий.

## Структура ассетов (уже на диске, `assets/эмоции/`)

24 PNG-файла в формате `{эмоция}+{поза}.png`. Это МАТРИЦА: 6 эмоций
лица × несколько переиспользуемых поз тела. Не каждая комбинация
существует — список конкретных файлов:

```
груст+деф.png          груст+думает.png        груст+подбадрив.png
груст+поздрав.png      груст+предупреж.png
деф+деф.png            деф+думает.png           деф+подбадрив.png
деф+поздрав.png        деф+предупреж.png
думает+деф.png         думает+думает.png        думает+подбадрив.png
предупреж+деф.png      предупреж+думает.png     предупреж+подбадрив.png
предупреж+поздрав.png  предупреж+предупреж.png
рад+деф.png            рад+думает.png           рад+подбадрив.png
рад+поздрав.png        рад+предупреж.png
удив+деф.png           удив+думает.png          удив+подбадрив.png
удив+поздрав.png       удив+предупреж.png
```

Шесть эмоций лица: `груст` (грустит), `деф` (дефолт/нейтрально),
`думает`, `предупреж` (предупреждает/обеспокоен), `рад` (радуется),
`удив` (удивлён).

Пять поз тела (переиспользуются под разные эмоции лица): `деф`,
`думает`, `подбадрив` (подбадривает), `поздрав` (поздравляет),
`предупреж` (предупреждающий жест).

**Важно: эмоция и поза — независимые оси.** Реализуй loader как
функцию `getMascotFrame(emotion, pose)` → путь к файлу, с fallback на
`{emotion}+деф.png`, если конкретная комбинация эмоция+поза не
существует в списке выше (не все 30 комбинаций есть, только 24).

## Задача 1 — таблица решения эмоции по успеваемости + событиям

Нужна чистая функция (без побочных эффектов), которая на основе данных
студента возвращает `{ emotion, pose }`. Используй такую логику
приоритетов (сверху вниз — первое совпадение побеждает):

### Приоритет 1 — разовые события (триггеры), если произошли недавно
(например, в последние 24–48 часов с момента последнего просмотра
дашборда — заведи поле типа `lastSeenAt` для сравнения):

| Событие | emotion | pose |
|---|---|---|
| Новая оценка 5 | `рад` | `поздрав` |
| Новая оценка 4 | `рад` | `думает` |
| Новая оценка 2 или «Н» (неявка) | `груст` | `предупреж` |
| Новая оценка 3 | `деф` | `думает` |
| Пропуск без уважительной причины зафиксирован | `предупреж` | `предупреж` |
| Экзамен/зачёт через ≤3 дня (по `lessons[].date`) | `предупреж` | `думает` |
| Пересдача назначена | `груст` | `думает` |
| Пересдача сдана успешно (статус «Зачтено») | `рад` | `подбадрив` |

### Приоритет 2 — если триггеров нет, общий тренд успеваемости
(сравни средний балл за последние N=5 оценок с средним за
предыдущие N=5; если данных меньше — сравни с общим средним):

| Состояние | emotion | pose |
|---|---|---|
| Средний балл ≥ 4.5 | `рад` | `деф` |
| Средний балл 3.5–4.49, тренд растёт | `рад` | `подбадрив` |
| Средний балл 3.5–4.49, тренд стабилен/падает | `деф` | `деф` |
| Средний балл 2.5–3.49, тренд растёт | `деф` | `подбадрив` |
| Средний балл 2.5–3.49, тренд падает | `предупреж` | `деф` |
| Средний балл < 2.5 | `груст` | `предупреж` |
| Посещаемость < 70% (независимо от баллов) | `предупреж` | `предупреж` |
| Нет данных вообще (новый ученик) | `удив` | `деф` |

### Приоритет 3 — "удивление" как редкая реакция
Если средний балл за последнюю единственную оценку отличается от
текущего среднего больше чем на 1.5 балла в любую сторону (резкий
скачок) — `удив` + `думает`, перекрывает приоритет 2, но не приоритет 1.

## Задача 2 — реализация

1. Добавь модуль (например `mascot.js` в вебе и `mascot.py` в
   десктопе) с функцией `resolveMascotState(studentData, events) →
   {emotion, pose, frame}`.
2. `frame` — путь к PNG через `getMascotFrame()` с fallback-логикой
   выше.
3. В умном совете (`loadTip()` / `_load_tip()`) рядом с текстом совета
   добавь `<img>` / `QLabel` с картинкой маскота, обновляемой при
   каждой генерации совета.
4. Анимация смены эмоции — простой fade (200–300мс), не дёргается
   резко при перерисовке дашборда.
5. Слой состояния чата (`говорит/думает/ждет/молчит`) НЕ трогать —
   он остаётся отдельным и используется только во время активной
   переписки в чате, а не в советах на дашборде.
6. Подели событие «новая оценка» на «увидено/не увидено» через локальное
   хранилище (`localStorage` в вебе, `secure_store`/локальный JSON в
   десктопе), чтобы триггер срабатывал один раз, а не при каждом
   открытии дашборда.

## Что НЕ нужно делать
- Не меняй существующую логику чата и его 4 кадра состояния.
- Не выдумывай новые файлы эмоций — используй только 24 существующих
  комбинации, с fallback на `{emotion}+деф.png`.
- Не делай эмоцию маскота источником правды для AI-промпта — это чисто
  визуальный слой поверх уже работающей логики совета.
